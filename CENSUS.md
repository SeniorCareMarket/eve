## What the big clusters are (sampled, not guessed)

1. **The deftype family is bigger than the step-1 model.** Eve
   code defines types through `eve.deftype-proto.macros` (aliased
   `eve`): `eve/host-deftype` and siblings, with CLJ protocol
   names (clojure.lang.ILookup etc.) auto-translated per host.
   Method names inside those bodies (valAt, equiv, -pr-writer,
   this, _) are the unresolved-symbol mass in src. Completing the
   kondo model for the deftype family is fix class 1.
2. **Macro-generated APIs are invisible.** eve.alpha's public API
   is generated by an `api-defs` macro (e/atom, e/count are
   unresolved-var everywhere); adapters generate vars the same
   way (adapters unresolved-var 405: t/attempt, t/submit, … via
   eve.thread's generated surface). Teaching: hooks or inline
   config for the generating macros — Eve-side kondo work, and
   the exports must carry it to consumers.
3. **contract-test/ is a vendored tree.** lib-ds (DataScript),
   lib (tonsky persistent-sorted-set) with PROVENANCE.md /
   PROVENANCE-DS.md: ports kept comparable to upstream. Its 639
   kondo findings + share of Splint are counted separately here
   and get the vendored treatment: a named exception, decided in
   this file — the vendored sources are NOT fixed and NOT
   reformatted by this campaign (they must stay diffable against
   their upstreams); the drivers/ code that is Eve's own stays in
   scope. (Same shape as cohost's stock tree, decided the same
   way: in writing, once, here.)
4. **Reader-conditional accounting.** unused-referred-var /
   unused-namespace / unused-binding carry the portable-.cljc
   pattern both Phase 1 retros measured: a refer used in only
   some #? arms reads unused. Per-site adjudication, not bulk
   deletion — deleting a "unused" refer that a host arm needs is
   how this campaign would break other hosts.
5. **redefined-var 211 (179 in adapters)** — adapters redefine
   the same seam namespace per host in one analysis pass; each
   host's eve.host/eve.crypto is a separate file defining the
   same vars. This is the multi-host layout, not 211 defects:
   the kondo pass over all hosts at once cannot model "one of
   these files per host". Adjudication: per-host kondo passes or
   a config answer — decided in the fix campaign, in the open.
