## Producer changes

- BEAM `eve.types/clje-translate-protos` emits persistent and transient protocol
  sets independently. Persistent `assoc`, `entry_at`, `contains_key`, `cons`,
  `empty`, etc. are no longer suppressed by `ITransientCollection`.
- Methods stay pooled by name, exactly as on the JVM. Declaring only
  `ITransientCollection` does not invent a transient associative implementation.
- `eve.clock/current-time-millis` delegates to the existing `eve.process/now-ms`
  host adapter (no duplicate host clocks).
- `eve.uuid/from-string`, `from-longs`, `most-significant-bits`,
  `least-significant-bits`, `to-words`, `random-uuid`, `squuid`, and
  `squuid-time-millis` work with native host UUIDs. Native UUID reader, existing
  `eve.net.u64` word arithmetic, and `eve.process/random-bytes` are reused.
- Two long halves mean signed 64-bit, big-endian. Decimal strings and word pairs
  preserve every bit even on JS. JS signed bit accessors return BigInt; unsafe
  Number inputs are rejected instead of silently rounding. UUID strings require
  canonical 8-4-4-4-12 shape, case-insensitive.
- Squuid prefix is unsigned Unix seconds modulo 2^32; subsecond milliseconds
  truncate toward zero. v4 version and RFC variant bits stay intact. Recovery
  returns the unsigned prefix in milliseconds, including past 2038 and wrap.
